# Badrinath Padmanabhan

I work on computer vision and applied machine learning at AIIMS New Delhi. My research focuses on assessing completed microsutures from images and understanding when a model's prediction needs expert review.

Previously, I worked at IIT Delhi on satellite-based socioeconomic measurement and groundwater modelling. I also worked remotely with Cardiff University on early prototypes for correspondence between prostate histopathology and MRI.

## Public code

### [Microsuturing image assessment](https://github.com/badri1995/microsuturing-assessment)

Selected research code for DINOv2 image representations, evidential regression, score-group classification and uncertainty estimation. Includes a portable cross-validation entry point. Research only, not a clinically validated decision tool.

### [Relative Wealth Index](https://github.com/badri1995/relative-wealth-index)

Research notebooks for census-based target construction, selected-feature random forest regression and a historical prediction experiment. The released notebooks document their input requirements and evaluation limits.

### [Groundwater modelling](https://github.com/badri1995/groundwater-modelling)

Geospatial preparation notebooks for associating monitoring wells with micro-watersheds and integrating groundwater development features. This initial release covers preparation stages, not the complete modelling pipeline.

These are source-only releases. Research datasets, images, annotations, notebook outputs and trained weights are not included.

### [Satellite indicators and village development](https://github.com/badri1995/ADI_complete)

A research workflow covering satellite imagery preparation, village extraction, CNN features, neighbourhood information, nightlights, population features, and regression against census indicators. The repository preserves the original stage-by-stage scripts and notebooks; it is not a packaged library.

### [Artistic style transfer](https://github.com/badri1995/artistic-style-transfer)

An image processing project exploring shadow maps, edge-preserving filtering, colour adjustment, quantized rendering, dithering, and colour transfer. This uses classical image processing methods rather than a neural style transfer model.

## Selected research

These summaries describe the broader research experience behind the selected code releases above.

### Microsuturing assessment

Image-based assessment of overall microsuturing quality and technical indicators. My work explores pretrained visual representations, regression and neural prediction heads, uncertainty estimation, and behaviour on unfamiliar images. This is ongoing research, not a clinically validated decision tool.

### Relative Wealth Index

Modelling relative socioeconomic development using satellite-derived village indicators, population, nightlights, census information, and neighbouring-village features. I developed the RWI modelling workflow and presented our collaborative poster at COMPASS 2024.

### Groundwater level modelling

Integrating monitoring-well records with aquifer, terrain, and hydro-climatic information to study groundwater-level changes at the micro-watershed scale. The workflow includes data cleaning, representative-well selection, feature integration, and regression evaluation with micro-watershed-based splits.
